# Product Requirements Prompt (PRP) — Strict DOM Isolation Fix ✅

## 1. Project Context & Objectives
The previous attempts to fix the UI layout failed due to CSS transform origin conflicts and the agent failing to relocate the Learn Mode banner. The Navigation component is currently flush against the bottom edge of the screen, and the Learn Mode popup is blocking the D-pad. The AI developer must strictly follow these instructions to use React Portals to force the Learn Mode banner to the top of the screen and rebuild the parent wrapper in `App.tsx` to explicitly protect the bottom margin.

## 2. Technical Decisions & Dependencies
* **Target Files:**
  * `components/navigation/NavContainer.tsx` (For the Learn Mode Banner).
  * Main View (`App.tsx` or `TonnetzGridContainer.tsx`) (For the widget wrapper).
* **Strategy:** * **Portal the Banner:** Wrap the `learnState.isActive && (...)` JSX block in `createPortal(..., document.body)` and forcefully style it to `fixed top-12`.
  * **Flexbox Anchor:** We will split the positioning and the scaling into two separate `div` wrappers in the main app to mathematically guarantee a 24px (`bottom-6`) gap.

## 3. Implementation Phases

### Phase 1: Portal the Learn Mode Banner — ✅ Completed
* **Objective:** Rip the Learn Mode banner out of the transformed container and render it at the top of the screen.
* **Instructions:**
  1. Open `NavContainer.tsx`.
  2. Ensure `createPortal` is imported from `react-dom` (it should be from the Context Menu fix).
  3. Locate the `learnState.isActive && (...)` rendering block at the very bottom of the component.
  4. Replace that block entirely with the following code:
     ```tsx
     {learnState.isActive && createPortal(
       <div className="fixed top-12 left-1/2 -translate-x-1/2 bg-black text-white px-6 py-3 border-2 border-yellow-400 shadow-xl z-[9999] animate-bounce pointer-events-auto">
         <p className="font-bold text-center">LEARN MODE ACTIVE</p>
         <p className="text-xs text-center mt-1 text-gray-300">Play a MIDI note (or press SPACE) to map: <span className="text-yellow-400 font-bold text-lg">{learnState.sequence[learnState.currentButtonIndex]}</span></p>
         <button onClick={stopLearnMode} className="block w-full text-xs underline mt-2 hover:text-yellow-400">Cancel</button>
       </div>,
       document.body
     )}
     ```
* **TDD Checkpoint:** * **Test Case 1:** [Given the code is updated, When the user triggers Learn Mode, Assert the banner appears strictly at the top of the viewport and is completely detached from the Navigation widget.]

### Phase 2: Dual-Wrapper Margin Fix — ✅ Completed
* **Objective:** Mathematically guarantee a bottom margin by separating the layout anchor from the scale transform.
* **Instructions:**
  1. Open the file where `<NavContainer />` is rendered (e.g., `App.tsx` or `TonnetzGridContainer.tsx`).
  2. Delete whatever `div` currently wraps the `<NavContainer />` component.
  3. Replace it with this exact, strict dual-wrapper structure:
     ```tsx
     {/* Absolute positioning anchor guaranteeing 24px bottom gap */}
     <div className="fixed bottom-6 left-0 w-full flex justify-center pointer-events-none z-50">
       {/* Scale transform strictly isolated from the anchor */}
       <div className="pointer-events-auto origin-bottom scale-[0.85]">
         <NavContainer />
       </div>
     </div>
     ```
* **TDD Checkpoint:** * **Test Case 1:** [Given the strict wrapper is applied, When the app renders, Assert the Navigation widget is physically prevented from touching the bottom edge of the screen, perfectly matching the margin of the adjacent UI cards.]
    * **Status Update:** "Transition Phase status to 🔵 Active. Execute the exact code replacement. Once verified, update status to ✅ Completed."
