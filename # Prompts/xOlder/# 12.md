# Product Requirements Prompt (PRP) — Inline Style Override ✅

## 1. Project Context & Objectives
The previous attempts to use Tailwind classes for the bottom margin failed because dynamic class compilation (`bottom-${Y}`) gets stripped by Tailwind's JIT compiler, leaving the widget flush against the screen. The objective here is to bypass Tailwind entirely for the vertical anchor and use an unbreakable React inline style to physically force the 24px gap.

## 2. Technical Decisions & Dependencies
* **Target File:** Main View (`App.tsx` or `TonnetzGridContainer.tsx` where `<NavContainer />` is mounted).
* **Strategy:** Use `style={{ bottom: '24px' }}` directly on the fixed wrapper to guarantee the browser renders the margin regardless of the Tailwind build step.

## 3. Implementation Phases

### Phase 1: Unbreakable Inline Margin — ✅ Completed
* **Objective:** Force the bottom margin using raw CSS.
* **Instructions:**
  1. Open the file where `<NavContainer />` is rendered (e.g., `App.tsx` or `TonnetzGridContainer.tsx`).
  2. Locate the wrapper `div` around the `<NavContainer />`.
  3. Replace the entire wrapper and component call with exactly this block of code:
     ```tsx
     <div 
       className="fixed left-1/2 -translate-x-1/2 z-[60] origin-bottom scale-[0.85] pointer-events-auto"
       style={{ bottom: '24px' }}
     >
       <NavContainer />
     </div>
     ```
  4. *Note to Agent:* Do NOT use `bottom-6` or any Tailwind `bottom-*` utility in the `className`. Rely exclusively on the `style` prop provided above.
