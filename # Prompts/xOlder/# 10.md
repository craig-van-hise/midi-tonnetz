# Product Requirements Prompt (PRP) — UI Margin Sync & Banner Anchoring ✅

## 1. Project Context & Objectives
The previous hardcoded layouts failed. The Navigation widget's bottom margin still does not match the side cards, and the Learn Mode banner was incorrectly moved to the top of the screen. The objective of this phase is to dynamically extract the exact margin class used by the existing side cards and apply it to the Navigation widget, and to anchor the Learn Mode banner directly above the Navigation component so it is contextually relevant but not blocking the controls.

## 2. Technical Decisions & Dependencies
* **Target Files:**
  * Main View (`App.tsx` or `TonnetzGridContainer.tsx`) (For margin syncing).
  * `components/navigation/NavContainer.tsx` (For the Learn Mode Banner).
* **Strategy:**
  * **Dynamic Margin Sync:** Inspect the DOM/React code for the existing left/right UI cards, extract their exact `bottom-*` class, and mirror it onto the Nav widget wrapper.
  * **Hover Banner:** Use `absolute` positioning with a negative `top` or a `bottom-[100%]` value to float the Learn Mode banner directly above the Navigation card.

## 3. Implementation Phases

### Phase 1: Margin Sync via Code Inspection — ✅ Completed
* **Objective:** Ensure the Navigation widget uses the exact same bottom margin math as the side cards.
* **Instructions:**
  1. Open the file rendering the side cards (likely `App.tsx` or `TonnetzGridContainer.tsx`).
  2. Locate the wrapper for the "Scroll to Pan" / "Click Node to Toggle" card (bottom-left) or the "Grid Axis" card (bottom-right).
  3. Identify the exact Tailwind spacing class used for its vertical placement (e.g., `bottom-8`, `bottom-12`, `mb-8`).
  4. Apply that *exact same class* to the outer fixed wrapper of the `<NavContainer />` component. 
  5. *Crucial:* Ensure `bottom-0` or `bottom-6` from previous attempts is completely removed. Ensure `origin-bottom` and `scale-[0.85]` remain on the inner wrapper.
* **TDD Checkpoint:** * **Test Case 1:** [Given the extracted class is applied, When the app renders, Assert the bottom edge of the Navigation widget forms a perfect horizontal line with the bottom edges of the side cards.]
    * **Status Update:** "Transition Phase status to 🔵 Active. Extract the class, apply it, and verify. Once verified, update status to ✅ Completed."

### Phase 2: Anchor the Learn Banner Locally — ✅ Completed
* **Objective:** Place the Learn Mode banner right over the Nav card.
* **Instructions:**
  1. Open `NavContainer.tsx`.
  2. Remove the `createPortal` wrapping from the Learn Mode JSX block (revert it to standard inline rendering).
  3. Update its `className` to position it absolutely, hovering just above the Nav card. Use the following exact string:
     `className="absolute -top-28 left-1/2 -translate-x-1/2 bg-black text-white px-6 py-3 border-2 border-yellow-400 shadow-xl z-50 animate-bounce w-max"`
* **TDD Checkpoint:** * **Test Case 1:** [Given the code is updated, When the user triggers Learn Mode, Assert the banner floats immediately above the Navigation D-pad, remaining in the lower-center of the screen without covering the arrows.]
    * **Status Update:** "Transition Phase status to 🔵 Active. Apply the class changes. Once verified, update status to ✅ Completed."
