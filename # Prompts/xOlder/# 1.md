
# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The objective is to integrate a modular, interactive Navigation Component (D-pad and action buttons) from a local external repository into the `midi-tonnetz` application. This component features customizable D-pad arrows, a Play/Home button configuration, and a MIDI "Learn Mode". The widget must be positioned as a floating overlay at the bottom of the Tonnetz Explorer interface without obstructing the underlying HTML5 Canvas interactions.

## 2. Technical Decisions & Dependencies
* **Target Directory:** `/components/navigation/`
* **File Migration List:** * `types.ts`
  * `NavControllerOriginal.tsx`
  * `NavContainer.tsx`
* **Missing Dependency Handling:** `ContextMenus.tsx` is required by `NavContainer.tsx` but is missing from the source ingestion. The developer must create a stub `ContextMenus.tsx` exporting empty/null functional components to satisfy the TypeScript compiler.
* **Iconography:** `NavControllerOriginal.tsx` utilizes `material-symbols-outlined` (`play_arrow`, `home`). According to the `midi-tonnetz` project state, Material Symbols are already integrated, so no refactoring to `lucide-react` is necessary.
* **Layout Strategy:** Wrap the instantiated `NavContainer` in a Tailwind-styled overlay (e.g., `fixed bottom-8 left-1/2 -translate-x-1/2 z-50 pointer-events-auto`) while ensuring the parent container uses `pointer-events-none` if it covers the screen, so background canvas clicks pass through.
