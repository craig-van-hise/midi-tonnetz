# Product Requirements Prompt (PRP) — Architecture Relocation & Layout Fix ✅

## 1. Project Context & Objectives
All previous layout attempts failed because the `<NavContainer />` was mounted globally in `App.tsx` (using screen-fixed coordinates), while the peripheral UI cards are mounted locally inside the `TonnetzGridContainer` (an 800px max-height relative box). The objective is to rip the Nav widget out of `App.tsx` and mount it directly inside `TonnetzGridContainer.tsx`, sharing the exact same `absolute bottom-4` coordinate system as the side cards. We will also anchor the "Learn Mode" banner directly above the D-pad.

## 2. Technical Decisions & Dependencies
* **Target Files:**
  * `components/TonnetzGridContainer.tsx` (New home for the widget).
  * `App.tsx` (To clean up old code).
  * `components/navigation/NavContainer.tsx` (For the Learn Mode Banner).
* **Strategy:** Move the component down the DOM tree into the relative grid container so it shares the exact same spatial context as the sibling cards.

## 3. Implementation Phases

### Phase 1: Relocate the Component — ✅ Completed
* **Objective:** Mount the Nav widget inside the grid container using matching local coordinates.
* **Instructions:**
  1. Open `components/TonnetzGridContainer.tsx`.
  2. Add the import: `import { NavContainer } from './navigation/NavContainer';`
  3. Scroll to the bottom of the component's JSX, just after the Instructions `<div className="absolute bottom-4 left-4...">...</div>`.
  4. Inject the Navigation wrapper exactly like this:
     ```tsx
     {/* Navigation D-pad floating overlay */}
     <div className="absolute bottom-4 left-1/2 -translate-x-1/2 z-50 origin-bottom scale-[0.85] pointer-events-auto">
         <NavContainer />
     </div>
     ```
