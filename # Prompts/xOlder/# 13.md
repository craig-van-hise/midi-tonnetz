# Product Requirements Prompt (PRP) — The Final Margin Nuke ✅

## 1. Project Context & Objectives
All external wrapper-based margin strategies have failed, leaving the Navigation card completely flush against the bottom of the viewport. We are abandoning parent-level positioning. The objective is to reset the external wrapper to absolute zero and inject the margin directly into the child component's core DOM element so it forces the browser to render the gap.

## 2. Technical Decisions & Dependencies
* **Target Files:**
  * Main View (`App.tsx` or `TonnetzGridContainer.tsx`).
  * `components/navigation/NavControllerOriginal.tsx`.
* **Strategy:** Reset the parent wrapper to `bottom-0` to eliminate rendering conflicts, and apply `mb-6` (margin-bottom: 24px) directly to the white card element.

## 3. Implementation Phases

### Phase 1: Clean the Parent Wrapper — ✅ Completed
* **Objective:** Remove all conflicting positioning math from the external wrapper.
* **Instructions:**
  1. Open the file rendering `<NavContainer />` (e.g., `App.tsx`).
  2. Locate its absolute wrapper `div`.
  3. Strip any `style={{ bottom: ... }}` properties and any `bottom-X` Tailwind classes.
  4. Set its exact class string to:
     `"fixed bottom-0 left-1/2 -translate-x-1/2 z-[60] origin-bottom scale-[0.85] pointer-events-auto"`
* **TDD Checkpoint:** * **Test Case 1:** [Given the wrapper is reset, When the compiler runs, Assert there are no syntax errors.]
    * **Status Update:** "Transition Phase status to 🔵 Active. Execute the reset. Once verified, update status to ✅ Completed."

### Phase 2: Internal Card Margin Override — ✅ Completed
* **Objective:** Force the 24px margin from the inside out.
* **Instructions:**
  1. Open `components/navigation/NavControllerOriginal.tsx`.
  2. Locate the main white card `div`. Its `className` string currently starts with:
     `"relative bg-white p-10 rounded-[2.5rem]..."`
  3. Inject `mb-6` at the very beginning of that class string. The new string MUST start exactly like this:
     `"mb-6 relative bg-white p-10 rounded-[2.5rem]..."`
* **TDD Checkpoint:** * **Test Case 1:** [Given the `mb-6` class is added, When the app renders, Assert the white card pushes itself exactly 24px away from the bottom edge of the screen, perfectly matching the adjacent cards.]
    * **Status Update:** "Transition Phase status to 🔵 Active. Execute the exact string replacement. Once verified, update status to ✅ Completed."
