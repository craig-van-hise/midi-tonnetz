# Product Requirements Prompt (PRP) — 🔘 Pending

## 1. Project Context & Objectives
The Navigation widget is currently mounted in the `midi-tonnetz` application, but relies on a stubbed version of `ContextMenus.tsx` which prevents the right-click configuration and MIDI Learn menus from appearing. Furthermore, the UI layout requires visual refinement: the component sits too high on the screen, is slightly too large, and lacks edge definition against the white canvas. This phase will restore the missing menu logic and polish the widget's layout footprint.

## 2. Technical Decisions & Dependencies
* **Target Files:**
  * `components/navigation/ContextMenus.tsx` (To be overwritten with provided source).
  * `components/navigation/NavControllerOriginal.tsx` (To add structural borders).
  * `App.tsx` or `TonnetzGridContainer.tsx` (To adjust wrapper positioning/scale).
* **Styling Adjustments:**
  * **Positioning & Scale:** Shift the parent wrapper's `bottom` value down (e.g., to `bottom-4` or `bottom-5`) to align horizontally with the adjacent UI cards. Apply a CSS transform (e.g., `scale-[0.85] origin-bottom`) to shrink the overall footprint.
  * **Edge Definition:** Add a subtle border (e.g., `border border-gray-200`) to the main navigation card container so it doesn't bleed into the Tonnetz grid.
