# Product Requirements Prompt (PRP) — Core Component Spacing Bugfix ✅

## 1. Project Context & Objectives
The Navigation widget continues to render too high on the screen because the internal component (`NavControllerOriginal.tsx`) has a hardcoded minimum height (`min-h-[400px]`) and is vertically centering its contents. This creates a massive invisible padding block that overrides any external bottom-margin positioning we apply to its parent wrapper. The objective is to remove this internal height constraint so the component tightly hugs the visual card.

## 2. Technical Decisions & Dependencies
* **Target File:** `components/navigation/NavControllerOriginal.tsx`
* **Strategy:** Use explicit string replacement to remove `h-full` and `min-h-[400px]` from the outermost wrapper, allowing the card to sit flush against whatever container it is placed in.

## 3. Implementation Phases

### Phase 1: Nuke Internal Minimum Height — ✅ Completed
* **Objective:** Remove the invisible 400px bounding box from the navigation component.
* **Instructions:**
  1. Open `components/navigation/NavControllerOriginal.tsx`.
  2. Locate the outermost `div` of the component. Its `className` currently looks exactly like this:
     `"relative w-full h-full min-h-[400px] flex flex-col items-center justify-center no-context-menu"`
  3. Replace that entire string with exactly this:
     `"relative w-auto h-auto flex flex-col items-center justify-center no-context-menu"`
* **TDD Checkpoint:** * **Test Case 1:** [Given the code is updated, When the app renders, Assert the white navigation card drops down significantly because the invisible 400px height wrapper has been removed.]
    * **Status Update:** "Transition Phase status to 🔵 Active. Execute the exact string replacement. Once verified, update status to ✅ Completed."

### Phase 2: Verify App-Level Anchoring — ✅ Completed
* **Objective:** Ensure the parent wrapper in `App.tsx` (or `TonnetzGridContainer.tsx`) is correctly anchoring the now tightly-hugged component.
* **Instructions:**
  1. Inspect the wrapper `div` around `<NavContainer />` in the main view.
  2. Ensure its class list includes `fixed bottom-6 left-1/2 -translate-x-1/2 z-50 origin-bottom scale-[0.85]`. (Adjust `bottom-6` up or down by a few pixels if needed to perfectly match the adjacent cards now that the 400px box is gone).
* **TDD Checkpoint:** * **Test Case 1:** [Given the height is fixed, When looking at the UI, Assert the bottom of the navigation card perfectly aligns with the bottom margin of the left and right info cards.]
