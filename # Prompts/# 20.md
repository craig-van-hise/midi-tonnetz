## 1. Project Context & Objectives
The Transformation Engine's `LEFT` logic was successfully corrected in Matrix 2. However, a secondary routing bug exists for the `UP` direction. The user observes that pressing the "Up" button yields the exact same transform sequence as "Left" (e.g., C Major $\rightarrow$ A Minor $\rightarrow$ A Major). This indicates that the "Up" command is erroneously applying a root shift of $+9$ (the value for Left) instead of its intended $+1$ when starting from a Base State ($F = 0$), or the UI layer is sending the wrong command string. The objective is to audit and correct the Matrix 1 mappings and UI event bindings.

* **Reference Matrix 2 ($F = 1$):**
