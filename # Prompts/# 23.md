# Product Requirements Prompt (PRP) — ✅ Completed

## 1. Project Context & Objectives
The 7th Chord State Engine contains a React side-effect anti-pattern. Because `setSeventhState` is invoked inside the `setState(prev => ...)` updater callback within `handleDirectionalTrigger`, React Strict Mode double-invokes the logic. This causes cyclical directional commands to fire twice per click (e.g., Cmaj7 -> C#m7 -> C#maj7 instantly). The objective is to decouple these state updates so the 7th chord logic executes exactly once per UI interaction.

## 2. Technical Decisions & Dependencies
* **State Decoupling:** `handleDirectionalTrigger` must evaluate the current active shape *outside* of the `setState` updater function.
* **Dependency Array Update:** To evaluate `state.I.length` directly, `state.I.length` must be added to the `useCallback` dependency array, allowing the function to branch safely before calling any setters.
