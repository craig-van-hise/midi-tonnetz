# Product Requirements Prompt (PRP) — 🔵 Active

## 1. Project Context & Objectives
Based on the codebase evidence (`App.tsx` and `TonnetzGrid.tsx`), the application currently utilizes a sophisticated chord-latching mechanic driven by a dual-map state (`down` for physical keys, `held` for visual retention) within `App.tsx`. 

The state collision bug occurs because the Canvas UI (`TonnetzGrid.tsx`) operates on Pitch Classes (0-11), while the `held` map operates on absolute MIDI note numbers (0-127). Currently, `App.tsx` passes state downwards but lacks a callback mechanism to allow the UI to mutate the `held` map. The objective is to establish a bidirectional data flow where clicking a grid node intelligently adds or removes its corresponding modulo-12 values from the central `held` map in `App.tsx`, preserving the exact chord-latching behavior.

## 2. Technical Decisions & Dependencies
* **Unified State Mutator:** Instead of creating conflicting state branches, the UI click event will mutate `App.tsx`'s `midiNoteState.held` map directly.
* **Modulo-12 Filtering:** When a Pitch Class (0-11) is clicked to be turned *off*, the logic must scan the `held` map and remove **all** absolute MIDI notes where `note % 12 === clickedPitchClass`.
* **Prop Drilling / Lifting State:** A new callback `onTogglePitchClass: (pc: number) => void` must be passed from `App.tsx` down through `TonnetzGridContainer` into `TonnetzGrid.tsx`.

### Phase 2: Modulo-12 Latch Mutation — ✅ Completed
* **Objective:** Implement the toggle logic to correctly modify the `held` map without breaking the `down` physical state tracking.
* **Instructions:**
    1. In `App.tsx`, complete the `handleTogglePitchClass(pc)` function.
    2. Read the current `midiNoteState.held`.
    3. Determine if the pitch class is currently active by checking if *any* key in the `held` map satisfies `key % 12 === pc`.
    4. **If Active (Turn Off):** Create a new `held` map. Iterate through the current `held` map and delete all entries where `key % 12 === pc`.
    5. **If Inactive (Turn On):** Create a new `held` map. Add the pitch class directly (e.g., `nextHeld.set(pc, 100)`). (Using the raw `pc` value 0-11 is safe since `pc % 12 === pc`).
    6. Update state: `setMidiNoteState(prev => ({ ...prev, held: nextHeld }))`.
